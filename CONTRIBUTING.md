# Contributing
1. Create a feature branch and keep changes scoped.
2. Never commit API keys, personal data, CCTV footage, or unverified claims about safety.
3. Add tests for scoring/routing changes.
4. Document the source, timestamp, confidence and limitations of any real-world dataset.
5. Run Python tests, Maven tests and frontend production build before submitting.
6. Use respectful, non-stigmatizing language; missing coverage must not be equated with danger.
